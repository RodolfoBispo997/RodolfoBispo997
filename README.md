## About me

Backend developer from Brazil with **5+ years of professional experience** building and maintaining SaaS, APIs, and database-driven systems.

My professional background is in PHP, Symfony, Laravel, MySQL, and production maintenance. I am currently focused on Node.js, TypeScript, NestJS, and scalable backend architecture.

## Featured project

### [DBMetrics — Database Observability SaaS](https://app.dbmetrics.com.br)

A full-stack SaaS for monitoring MySQL and PostgreSQL databases, collecting metrics, retaining historical snapshots, and managing alert rules.

- Built the API with **Node.js, TypeScript, NestJS, Prisma, and PostgreSQL**, organized with DDD and Clean Architecture.
- Implemented authentication, email verification, role and ownership controls, encrypted connection credentials, SSRF protection, timeouts, rate limiting, and TLS-verified database connections.
- Implemented metric collection, alert execution history, and email notifications.
- Deployed the API to **AWS ECS** and the frontend to **Vercel**.
